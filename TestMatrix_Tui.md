## Observation surfaces

Kitty 0.32.2 ran as an X11 window under GNOME Wayland/XWayland. XTest supplied native keys/mouse; Kitty screen text, ANSI attributes and actual X-window images supplied observations. UTF-8 byte replay was used only for explicitly scripted text entry; xclip supplied desktop clipboard exchange. Terminal byte replay is identified separately from native terminal keyboard/mouse delivery. X11 clipboard access is optional at runtime and uses the compositor’s XWayland bridge on Wayland desktops; without DISPLAY, clipboard objects remain process-local. Wayland global hotkeys and SGR mouse Super are not provided by the existing platform/terminal protocols.

The build used a temporary, uncommitted XFixes development sysroot because system package installation was unavailable. The committed prerequisite script lists the normal system packages.
